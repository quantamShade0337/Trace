# Product

## Register

product

## Users

Everyday Mac users and technically experienced users who want to understand network activity, identify the apps involved, and investigate a connection without learning networking terminology first. These audiences and goals come from AGENTS.md.

## Product Purpose

Make real network activity understandable in a native macOS utility. The user's redesign request makes a MapKit globe and curved connection paths the visual focus. Preserve the working inspector, diagnostics, persistence and protection foundation.

## Brand Personality

Precise, calm, considered. A carefully crafted Apple-platform utility, with a readable workflow and restrained presentation.

## Anti-references

The previous sparse dashboard is not the design target. Avoid giant statistic cards, decorative cybersecurity styling, neon, glass panels, fabricated traffic, invented locations and dense technical explanations in the primary flow.

## Design Principles

1. Start with the user's question: which app is connecting, where approximately, and how to investigate it.
2. Make the globe useful: select a destination to connect geography with process ownership and connection details.
3. Distinguish IP geolocation estimates, conceptual endpoint arcs and measured traceroute hops.
4. Show a concise explanation first; reveal technical evidence and configuration progressively.
5. Keep network metadata local unless the user explicitly requests a disclosed external lookup.

## Accessibility & Inclusion

Use native controls and keyboard navigation, semantic text and contrast, selection states beyond colour alone, reduced-motion support, resizable layouts, and accessible textual alternatives to the map. Maintain dark and light appearances as required by AGENTS.md.
